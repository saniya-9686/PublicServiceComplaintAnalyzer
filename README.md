# Public Service Complaint Priority Analyzer

An interactive data analysis dashboard built with Python and Streamlit that studies public service complaints from Bengaluru (BBMP grievance data from OpenCity). It helps show which types of complaints, wards and time periods need the most attention.

## Problem
Cities receive thousands of complaints about roads, garbage, drainage, streetlights and more. Without analysis, it is hard to see which issues are most common, which wards are most affected and which complaints should be handled first.

## Features
- Overview cards with key complaint numbers
- Charts by category, status, ward and trend over time
- Data quality checks for duplicate and missing values
- Priority analysis to identify complaints that need quick action
- Filters for ward, category and priority

## Tech Stack
- Python
- Streamlit
- Pandas

## Dataset
BBMP grievance data from the OpenCity portal (public dataset).

## How to Run
1. Install Python.
2. Install the libraries: `pip install streamlit pandas`
3. Keep the dataset file in the same folder as `app.py`.
4. Run: `streamlit run app.py`
